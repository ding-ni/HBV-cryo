# HBV-Cryo

本目录只保留两个入口：

- `01_训练率定.py`：公开入口
- `率定核心.py`：模型核心

`率定核心.py` 当前包含：

- 格网 HBV 产流
- 两分区 `CFMAX` 度日融雪 / 融冰
- `UZL` 在内的全有效参数率定
- 雨源、雪融、冰融三组分追踪
- 可选上游边界入流
- 两参数马斯京根汇流
- `glacier_melt` 参考序列对比输出
- 可配置时间步长，默认 `24 h`

小时尺度说明：

- 若使用 `1 h` 时间步长，请在配置中把 `时间步长_小时` 改为 `1`
- 同时需要小时尺度的气象输入、观测流量和边界入流
- 若时间字段只写日期，核心会自动把结束时刻解释为当天最后一个时间步
