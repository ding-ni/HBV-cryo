# HBV-Cryo

HBV-Cryo 是面向寒区流域的分布式 HBV 水文模拟与率定系统。工程包含模型计算内核、数据准备脚本和 HBV-Studio 图形化工作流，可用于日尺度或可配置时间步长下的流域径流模拟、参数率定、结果诊断与过程组分分析。

## 工程结构

- `HBV-Cryo/`：模型主干、率定入口、目标函数与结果输出逻辑。
- `HBV-Studio/`：图形化工作流、后端服务、前端界面与任务调度。
- `数据准备/`：地理数据、气象数据、观测径流等输入准备脚本。
- `配置/`：流域配置模板与小型示例配置。
- `公共/`：跨流程复用的公共函数与内部实现。
- `dev_tools/`：开发验证辅助工具，不作为常规建模入口。

## 模型能力

- 分布式栅格化 HBV 产流计算。
- 降雨、降雪、融雪和冰川融水过程组分追踪。
- 单阈值两分区 `CFMAX` 融雪/融冰参数结构。
- 土壤含水、上层线性水库、下层线性水库与马斯京根汇流。
- 可选冰川模块和上游边界入流模块。
- 支持默认日尺度计算，并保留可配置时间步长接口。
- 支持 Monte Carlo、差分进化及局部细化等率定流程。

## 基本使用

1. 基于 `配置/流域配置模板.json` 创建流域配置，或在 HBV-Studio 中新建工程。
2. 准备流域边界、DEM、观测径流、降水、气温和潜在蒸散发等输入数据。
3. 使用图形化工作流运行：

   ```powershell
   python HBV-Studio/launch.py
   ```

4. 或使用模型脚本入口运行：

   ```powershell
   python HBV-Cryo/01_训练率定.py
   ```

## 开发检查门禁

前后端重构、界面专业化和打包相关修改，在提交前至少运行：

```powershell
python dev_tools/studio_baseline_check.py
```

该检查会覆盖 Python 语法、前端 JavaScript 语法、`studio_service.py` API 路由快照、源码 / Demo / 安装包关键路径，以及源码启动链 `/api/health`。如果有意新增、删除或改名 API 路由，先人工确认兼容性，再更新快照：

```powershell
python dev_tools/studio_baseline_check.py --update-api-snapshot
```

`pytest` 可用时，再补充运行：

```powershell
python -m pytest HBV-Studio/tests
```

## 数据输入说明

- 流域边界通常使用矢量数据，DEM 使用栅格数据；冰川边界为可选输入。
- 观测径流可使用 CSV 或 Excel 文件，需包含日期和流量字段，具体字段名由工作流配置或导入步骤解析。
- 降水、气温和潜在蒸散发可使用本地格点数据，也可通过已接入的数据源流程准备。
- ERA5 降水、气温和潜在蒸散发流程在配置满足条件时可用于自动准备输入。
- MSWEP 和 CMFD 当前按本地已有数据源处理；若需要自动下载，应在数据源接口层单独扩展。
- 模型不强制固定空间分辨率，实际分辨率以 DEM、流域掩膜和气象输入对齐结果为准。

## Git 数据边界

本仓库用于保存源码、配置模板、小型示例和必要文档。以下内容不应提交到 Git：

- 用户运行目录、运行结果、缓存和日志。
- 原始或派生的大体量水文、气象、GIS、遥感数据。
- 本机绝对路径、个人工作区配置、临时验收记录。
- 安装包、压缩包、打包中间目录和可执行构建产物。

需要共享的大文件或正式安装包应通过独立发布渠道、对象存储或交付目录管理，而不是直接放入源码仓库。
