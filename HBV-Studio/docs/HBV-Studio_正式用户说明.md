# HBV-Studio 正式用户说明

## 1. 软件定位

HBV-Studio 面向流域水文建模、冰雪融水过程复核和率定结果整理。界面默认保留正式建模所需入口：工作区配置、输入完整性检查、手动调参、正式率定、结果分析和结果导出。

## 2. 推荐工作流

1. 在“项目向导”中创建或打开工作区，填写流域、时间分段、观测流量、气象驱动、DEM、冰川边界和可选边界入流。
2. 在“输入完整性检查”中确认率定所需资料已就位。检查未通过时，先回到提示的步骤补齐数据。
3. 如需人工复核参数响应，可先在“结果分析”中生成手调起点，再按雪过程、土壤过程、产汇流、河道路由、冰川过程分组调整。
4. 输入检查通过且参数范围确认后，进入“率定运行”，启动正式率定。
5. 在“结果分析”中查看水文摘要、过程线、组分分解、残差、参数和本地过程复核报告，并按时间范围导出 Excel。

只有一年资料时，可直接把年初至率定开始前设置为年内预热，并将预热段排除在评价指标之外。干/湿初始状态敏感性是可选诊断，不是运行门槛。ERA5 累计型降水和辐射在转换日量时仍需包含次日 `00:00` 收尾样本，这是累计量读取规则，与是否采用多年预热无关。

## 3. 结果解释

结果页默认显示水文摘要，详细逐年复核保存在结果目录的 `水文过程复核报告.md`。

三源比例采用模型输出的三类全流域水源分量：

- `q_rain`：降雨产流。
- `q_snow`：积雪融化形成的融雪径流。
- `q_ice`：裸冰融化形成的融冰径流。

报告中的降雨、融雪、融冰比例使用同一径流分母计算。完整上游流域使用率定期模拟总流量；区间流域带上游边界入流时，比例使用本地径流口径，不把外部边界入流计入三源分量。

这些比例用于判断当前工程配置下的水文过程是否合理。解释时应同时查看降水时序、温度条件、积雪消融、冰川范围、径流过程线、洪峰年份和退水过程，不应只看单一比例。

区间项目的出口 NSE/KGE 代表包含上游边界流量的出口总流量拟合。路由后的上下游观测残差、模拟本地产流、负残差体积和区间洪量用于解释本地区间产流，但这些诊断不阻止项目运行；报告时只需把“出口总流量拟合”和“区间本地产流诊断”分开表述。

## 4. 导出与交付

结果目录保存本次运行的模拟序列、参数、指标、图表所需数据和过程复核报告。正式交付时建议至少保留：

- `simulation.csv`
- `水文过程复核报告.md`
- Excel 导出文件
- 工作区配置文件
