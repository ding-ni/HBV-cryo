# HBV-Studio 2026.10.05.1

本版本把 ERA5/ERA5-Land 的输入质量检查提升为模型运行前的阻断式契约。

## 变更

- 保留已核实的 ERA5-Land `ssrd` 单点缺测修复：2023-01-28 01:00 UTC、约 92.2°E/29.6°N。只用四个周边网格点双线性插值，并写出修复清单。
- 新增 `hbv_era5_quality_report_v1`：检查 NaN、Inf、填充值、空数组、时间坐标、重复时间、内部时间缺口、经纬度坐标和要求的时间样本，并记录源文件大小与 SHA256。
- 日尺度、小时尺度 ERA5 处理和前处理工具 NC→TIF 流程均在聚合、累计差分、重投影、TIF 写出之前执行质量审计；未知缺测会先写 JSON 报告再阻断。
- 应用和构建契约版本统一为 `2026.10.05.1`。

## 验证范围

- Python 语法检查通过。
- ERA5 累计边界回归测试通过。
- 前处理工具合同/UI 测试通过。
- 新增质量审计回归测试覆盖合法数据、NaN/Inf/填充值、重复时间、内部缺口、坏坐标、源文件哈希、已知 `ssrd` 修复和未知缺测阻断。

六套正式长预热方案不随源代码提交自动宣称完成。它们必须在各自工作区的原始 ERA5、日/小时强迫、站点观测、边界样本、配置和时间覆盖全部通过质量门控后，才能使用快速筛选 5000、12 线程、36 轮、候选倍率 12、精修 24 启动。
