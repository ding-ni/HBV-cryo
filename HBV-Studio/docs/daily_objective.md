# 日尺度率定与独立径流验证

当前目标函数族仍为 `daily_unified_professional_v1`，评分口径为
`calibration_only_v1`。随机筛选、全局搜索、局部精修和阶段选优只使用
率定期实测流量。验证期的流量指标继续计算和展示，权重和罚项固定为零。
本口径适用于连续日尺度统一目标函数；小时尺度及场次洪水目标需按各自合同检查。

## 连续计算与分段评价

每组候选参数都从配置的初始状态开始，连续运行预热、率定和验证时段。
预热用于建立积雪、土壤水和响应库状态；没有实测流量的预热日不参与流量拟合。
率定结束后使用同一组最优参数与连续状态计算验证结果，进入验证期时不清空状态。

按完整观测年筛选时，率定与验证分别判断自己时段内的完整年份与回退样本；
同一日历年内的验证缺测不得改变率定样本。混合回退记录为
`full_year_with_period_fallback`，不把不完整年份伪装成完整观测年。

验证指标可以用于解释结果。如果依据验证结果反复调整参数范围、降水规则或
初值，并挑选表现最好的版本，该时段便不再是独立验证，需要另留评价时段。

## 实际评分

率定期流量主体项保持原有权重：

```text
flow = (1 - NSE_cal)
     + 0.35 * (1 - logNSE_cal)
     + 0.10 * abs(PBIAS_cal) / 100
```

`logNSE_cal` 不可计算时沿用原逻辑回退到 `NSE_cal`；`PBIAS_cal` 不可计算时
跳过该项。`NSE_cal` 无效时该候选不是有效率定解，良好的验证指标不能补救。

`flow_guard` 只对率定期指标施加连续软惩罚：

| 率定指标 | 参考阈值 | 容差 | 惩罚权重 |
| --- | ---: | ---: | ---: |
| NSE | 不低于 0.60 | 0.20 | 3.0 |
| KGE | 不低于 0.65 | 0.20 | 2.0 |
| 绝对 PBIAS | 不高于 15% | 10% | 1.5 |

验证期仍可展示这些阈值的诊断状态，但检查项 `active=false`、
`diagnostic_only=true`、`weight=0`、`penalty=0`，不改变总目标或候选排序。

总目标仍为：

```text
flow + flow_guard
+ min(seasonality + process_signatures + cryo_consistency + external_evidence, 0.35)
+ ice_dominance_guard
```

季节分配、过程特征、冰雪时序和外部证据项按 `calib_mask` 取样。冬季实测缺少
或率定期只覆盖夏季时，不能用验证期数据补齐这些观测约束。默认外部冰融水参考
不参与目标。物理状态和气象强迫可以连续计算，不意味着验证期流量可参与调参。

缺少冬季样本时，冬季融冰诊断应显示为未检查；零个冬季样本不能作为
冬季融冰为零或冬季物理检查通过的证据。

## 连续输出与分量比例

新的 `simulation.csv` 保存预热、率定、验证的全部连续计算结果。缺测上游边界
期间，出口总流量保留缺测，本地产流和雨、雪、冰分量仍保存。旧结果若只保存了
率定及验证时段，界面与导出按实际 CSV 日期说明，不宣称预热结果已经保存。

每个评价期的分量比例共用该期有效出口模拟与观测配对日期；上游与本地比例、
本地雨雪冰比例均不得混用不同日期。`fraction_sample_count` 记录实际分量样本数。
没有有效配对或分母为零时，比值记为缺失，不把无法计算的贡献显示为零。
这些比例是对应评价日期的模型分量，不能称为全年实测水源比例。

## 记录与回归检查

目标函数结果和日尺度目标元数据记录 `objective_scoring_policy=calibration_only_v1`、
`optimization_period=calibration_period`、`validation_diagnostic_only=true`。
历史结果保持原始记录；具有验证期非零优化权重的历史率定，不能追认成独立验证。

`tests/test_daily_objective_validation_isolation.py` 固定模拟序列及率定期数据，
改变验证实测、验证指标和样本数，确认总目标及所有非流量项不变；还检验当验证
实测偏向另一候选时，率定选优顺序仍保持不变。
