# 降水方案说明

## 推荐优先级

### 1. `grid_only`
- 含义：直接使用 `1 km` 格点降水。
- 用途：快速建立基线结果。
- 优点：最简单，最适合作为第一版。
- 适用阶段：所有对象的首轮试运行。

### 2. `grid_plus_station_bias`
- 含义：以 `1 km` 格点降水为主，再用站点做偏差订正。
- 用途：正式方案优先推荐。
- 优点：
  - 保留格点的空间分布
  - 同时吸收站点实测信息
- 适用阶段：对象一和对象二的正式结果版本。

### 3. `thiessen_station_only`
- 含义：只用站点，通过泰森多边形把降水分配到流域。
- 用途：快速对比方案或数据缺失时的临时替代。
- 风险：
  - 会丢失格点降水的空间细节
  - 对山地流域通常不是最终优选方案
- 建议：只作为基线对照，不建议直接作为最终成果。
